# 芯棋 XinQi 编译指南

从源码构建芯棋所需的完整步骤。如果你不想编译，直接从 [Releases](https://github.com/Hxygw/--XinQi/releases) 下载预编译包即可。

---

## 前置依赖

| 组件 | 版本要求 |
|------|----------|
| Visual Studio | 2022 (v145 工具集) |
| Windows SDK | 10.0 (x64) |
| Node.js | 18+ |
| MSBuild | VS 2022 自带（见下方说明） |

> **关于 MSBuild**：如果 `MSBuild` 命令在命令行中找不到，请使用 VS 2022 安装目录下的完整路径，例如：
> ```
> "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe"
> ```
> 或用 Visual Studio 自带的 **Developer Command Prompt**，MSBuild 已自动在 PATH 中。

---

## 构建脚本（推荐）

项目根目录提供一键构建脚本，自动完成 C++ 编译 + 前端构建 + 打包：

```cmd
build_roomserver.bat
```

---

## 分步构建

### 1. 编译 C++ 后端

#### XinQiCore（核心引擎）

```cmd
MSBuild XinQiCore\XinQiCore.vcxproj /p:Configuration=Release /p:Platform=x64
```

#### XinQiServer（本地对弈 + AI）

```cmd
MSBuild XinQiServer\XinQiServer.vcxproj /p:Configuration=Release /p:Platform=x64
```

#### XinQiRoomServer（联机对战，可选）

```cmd
MSBuild XinQiRoomServer\XinQiRoomServer.vcxproj /p:Configuration=Release /p:Platform=x64
```

> **64 位链接器**：如果链接时遇到内存不足（LNK1257），追加参数 ` /p:PreferredToolArchitecture=x64` 使用 64 位链接器。

### 2. 构建前端

#### 主前端（本地对弈 + AI）

```cmd
cd xinqi-frontend
npm install
npm run build
```

产物输出到 `xinqi-frontend/dist/`，需复制到 `XinQiServer/dist/`。

#### 房间前端（联机对战，可选）

```cmd
cd xinqi-room-frontend
npm install
npm run build
```

产物输出到 `xinqi-room-frontend/dist/`，需复制到 `XinQiRoomServer/x64/Release/dist/`。

### 3. 构建训练 DLL（可选）

用 Visual Studio 打开 `XinQiTrain\XinQiTrain.vcxproj`，编译 Release/x64 配置，产物为 `XinQiTrain\XinQiTrain.dll`。

## 常见问题

### Q：编译报 C4819 编码警告

源码使用 UTF-8，简体中文 Windows 下 MSVC 默认用 GBK 代码页解析 UTF-8 中文注释时会触发此警告。已在所有 vcxproj 中配置了 `/utf-8` 编译选项，通常不会出现。如果遇到，请确认 `.cpp` / `.h` 文件保存为 **UTF-8 无 BOM** 格式。

### Q：链接时报 LNK1257 内存不足

32 位链接器在处理大项目时可能空间不够。在 MSBuild 命令末尾追加：

```cmd
/p:PreferredToolArchitecture=x64
```

### Q：构建产物体积异常偏大

Release 编译时中间 `.obj` 文件可能很大（如 13MB），这是 `/GL` 全程序优化的中间产物，不影响最终 `.exe` 体积。
