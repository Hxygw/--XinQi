# 芯棋联机对战指南

芯棋附带独立房间服务器（XinQiRoomServer），支持多人在线对战。4 位房间号，好友秒入。手机电脑均可，无需注册账号。

---

## 快速上手

### 房主：开房

**① 启动 RoomServer**

下载最新版 `XinQiRoomServer-v0.1.0.zip` 并解压，双击 `XinQiRoomServer.exe`。控制台出现以下输出即表示启动成功：

```
XinQi Room Server listening on http://localhost:8090
Share via: ngrok http 8090
```

> 无需安装任何东西——单 exe，零依赖。

**② 让好友能连到你**

你和好友需要在**同一个网络**才能直连。根据你们的情况选一种方式：

| 场景 | 方法 | 难度 |
|------|------|------|
| 同一个局域网（同一 WiFi / 同一办公室） | 直连，见下文"局域网联机" | ⭐ |
| 不在同一个网络 | 用 ngrok 穿透，见下文"公网联机" | ⭐⭐ |
| 有公网 IP 或云服务器 | 改监听地址，见下文"高级" | ⭐⭐⭐ |

**③ 打开页面，创建房间**

浏览器打开 `http://localhost:8090`，点击 **创建房间**。页面会显示一个 4 位房间号（如 `3825`）。把房间号告诉好友即可。

### 朋友：加入

浏览器打开房主给的地址，输入 4 位房间号，点击 **加入**，然后点 **准备**。房主点 **开始游戏**，直接开战。

---

## 局域网联机（最简单）

你和好友连同一个路由器/同一个 WiFi 即可。

### 第一步：找到房主的局域网 IP

在房主的电脑上打开命令提示符（Win+R → `cmd`），输入 `ipconfig`，找到类似这样的行：

```
IPv4 地址 . . . . . . . . . . . . : 192.168.1.101
```

记下这个地址（如 `192.168.1.101`）。

### 第二步：好友访问

好友在浏览器地址栏输入：

```
http://192.168.1.101:8090
```

注意：**必须用房主的实际 IP 地址**，不能用 `localhost`。局域网联机不需要 `ngrok`。

### 常见问题

| 问题 | 原因与解决 |
|------|-----------|
| 好友打不开页面 | 检查防火墙是否拦截了 8090 端口。Windows 可能会弹窗询问"允许此应用通过防火墙"，选择"允许"。如果没有弹窗，手动去**控制面板 → 防火墙 → 允许应用通过防火墙**添加 `XinQiRoomServer.exe` |
| 手机连不上 | 确保手机和电脑在同一个 WiFi 下。手机的浏览器输入 `http://192.168.1.101:8090`（注意是 http，不是 https） |
| IP 地址变了 | 家庭网络路由器的 DHCP 会动态分配 IP，重启路由器后 IP 可能变化。下次联机前重新查一次即可 |

## 公网联机（不同网络）

不在同一个 WiFi 时需要内网穿透。这里用 **ngrok** 举例（免费、无需注册即可用）。

### 第一步：下载 ngrok

从 [ngrok 官网](https://ngrok.com/download) 下载 Windows 版本，解压得到一个 `ngrok.exe`。把它放到 RoomServer 同目录下，或放到任何方便的目录。

### 第二步：启动 ngrok 隧道

确保 XinQiRoomServer 已经在运行（端口 8090），打开另一个命令提示符窗口，进入 ngrok.exe 所在目录，运行：

```cmd
ngrok http 8090
```

你会看到类似输出：

```
Forwarding  https://abc123.ngrok-free.app -> http://localhost:8090
```

记下那个 `https://abc123.ngrok-free.app` 地址。这个就是你的**公网地址**。

### 第三步：告诉好友

把上面那个地址发给好友。好友在浏览器打开即可进入房间页面。

之后你创建房间，好友输入房间号加入，流程和局域网完全一样。

> **ngrok 免费版注意事项：**
> - 每次启动 ngrok 会生成不同的随机地址
> - ngrok 免费版有连接数限制（每月 40 连接数配额，通常够日常使用几次）
> - ngrok 启动后不要关掉那个窗口，保持它在后台运行
> - 免费版可能会显示 ngrok 的中间页面，点"Visit Site"继续即可
> - 如果不想用 ngrok，也可以用 `frp`、`Tailscale` 或其他隧道工具，原理相同

### 我在自己电脑上搭建服务器，能让朋友随时连进来吗？

可以，但有前提：

1. **家庭宽带一般没有公网 IP**（运营商分配的是内网 IP），用 ngrok 是最简单的方案
2. 如果你确定自己有公网 IP（打电话问运营商确认），可以改 RoomServer 监听 `0.0.0.0`（见"高级设置"），然后在路由器上做**端口转发**：把外网 8090 端口转到你电脑的 8090 端口
3. 最简单稳定的方案：买一台便宜的云服务器（如腾讯云轻量、阿里云 ECS），在上面运行 RoomServer

> 对于偶尔和好友下几盘，ngrok 完全够用。

## 高级设置

### 更改监听端口

RoomServer 默认监听 8090 端口。如需更改，修改 `XinQiRoomServer\src\main.cpp` 中的 `int port = 8090;` 这一行，重新编译。

### 监听所有网络接口（危险）

RoomServer 默认只监听 `127.0.0.1`（仅本机可访问），这是出于安全考虑。如果你确定你的网络环境安全（比如在云服务器上），可以改为监听 `0.0.0.0`：

修改 `main.cpp` 中 `svr.listen("127.0.0.1", port);` → `svr.listen("0.0.0.0", port);`，重新编译。

> ⚠️ 改为 `0.0.0.0` 后，任何人知道你的 IP 和端口就能连上你的 RoomServer。建议仅在云服务器或信任的局域网环境下使用。

### 云服务器部署

1. 将编译好的 `XinQiRoomServer.exe` 和 `dist/` 目录上传到云服务器
2. 修改监听地址为 `0.0.0.0`（见上文）并重新编译，或在服务器上用 ngrok 转发
3. 在云服务器的防火墙中开放 8090 端口（TCP）
4. 运行 `XinQiRoomServer.exe`

建议使用 `screen` 或类似的终端复用工具保持程序在后台运行。

## 文件结构

一个完整的 RoomServer 分发包包含：

```
XinQiRoomServer/
├── XinQiRoomServer.exe    # 服务器程序（约 500KB）
└── dist/                   # 前端页面（由 xinqi-room-frontend 构建）
    ├── index.html
    └── assets/
        └── *.js, *.css
```

确保 `dist/` 目录和 `exe` 在同一目录下，否则页面无法加载。
